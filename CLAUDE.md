# Claude Code Guidelines - Apify Project

## Environment & Authentication
- `APIFY_TOKEN` is configured in `.env` and system environment.
- Apify CLI is available at `apify`.
- Apify Client SDKs are available for Node.js (`apify-client`) and Python (`apify-client`).

## Apify Skills & Tools
- Skills available: `apify-ultimate-scraper`, `apify-actor-development`, `apify-actorization`, `apify-integration-development`.
- MCP tools: `search-actors`, `fetch-actor-details`, `call-actor`, `get-actor-run`, `get-dataset-items`.
- Always check `AGENTS.md` for full platform rules, bill caps, and schema handling.
